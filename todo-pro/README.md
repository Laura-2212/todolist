# To-Do Pro

O **To-Do Pro** é uma demonstração de frontend desenvolvida em React com Vite para gerenciamento e visualização rápida de tarefas.

## 🚀 Finalidade do Sistema
O objetivo desta demonstração é apresentar a interface base da futura aplicação de tarefas, exibindo visualmente a lista de atividades, a criação de novas tarefas dinâmicas e a distinção clara entre itens **pendentes** e **concluídos**.

## 🛠️ Tecnologias Utilizadas
- **React** (JSX)
- **Vite**
- **CSS3** (com layouts responsivos via Flexbox/Grid)
